# 📺 YouTube Hashtag Finder

Este é um app em Python com Streamlit que busca vídeos no YouTube usando uma hashtag específica e exibe os resultados diretamente na interface, de forma simples e intuitiva.

## 🚀 Funcionalidades

- 🔍 Busca vídeos do YouTube com base em hashtags
- 📋 Exibe título, descrição e link do vídeo
- 💡 Interface amigável e fácil de usar

---

## 🧰 Tecnologias Utilizadas

- [Python](https://www.python.org/)
- [Streamlit](https://streamlit.io/)
- [YouTube Data API v3](https://developers.google.com/youtube/v3)
